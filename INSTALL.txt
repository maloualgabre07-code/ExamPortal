Install:
1. Stop the ExamPortal server.
2. Back up your current public/style.css.
3. Extract this ZIP into your ExamPortal project folder, preserving the public folder path.
4. Replace public/style.css when prompted.
5. Run npm start and hard-refresh the browser with Ctrl+F5.

Only public/style.css is included. No database, authentication, or exam logic is changed.
