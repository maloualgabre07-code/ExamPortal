EXAMPORTAL — FORGOT PASSWORD WITH GMAIL

Works for active registered accounts. It resets the ExamPortal password, not the user's Google/Gmail password.
A 6-digit code is emailed to the registered address. The user enters that code and a new password.
Codes expire after 10 minutes, work once, and lock after five incorrect guesses.
Requesting a new code replaces the old code. Resend cooldown: 60 seconds. Maximum: 3 requests/hour/account.
There are also shared IP request limits. Restarting the app does not reset per-account limits or failed-code counts.
Codes are stored as keyed hashes, not plaintext. Gmail credentials remain on the server in .env.
Successful reset invalidates previous login sessions. Account roles, classes, exams, answers and results are preserved.

INSTALL
1. Stop the server with Ctrl+C. Back up your project folder and database.
2. Extract ALL files directly into:
   C:\Users\Malou Algabre\OneDrive\ExamPortal\ExamPortal
   Replace matching files and merge folders. Preserve your existing .env and db.js.
   This cumulative update includes Inter fonts, smooth logout and required class codes.
3. In the project terminal run:
   npm install
   node scripts/upgrade-password-reset.js
   If the required class-code update has not yet been applied, also run:
   node scripts/upgrade-required-class-code.js
4. Configure the Gmail sender using the steps below.
5. Run node scripts/check-gmail.js to verify sender authentication (no email sent by that check).
6. Run npm start. Open http://localhost:3000 and press Ctrl+F5.

GMAIL SENDER SETUP — DO THIS ONLY ON YOUR OWN COMPUTER
Use a dedicated Gmail address for ExamPortal if available.
A. Open https://myaccount.google.com/security and sign in to the sender Gmail account.
B. Enable 2-Step Verification and complete Google's prompts.
C. Open https://myaccount.google.com/apppasswords
D. Create an app password named ExamPortal. Copy the generated 16-character app password.
E. In VS Code, open your project's existing .env. ADD these two lines (do not erase other settings):
   GMAIL_USER=your-sender-address@gmail.com
   GMAIL_APP_PASSWORD=your16characterapppassword
Replace both placeholders locally. Use the generated App Password, NOT your normal Gmail password.
Do not send either your .env file or the App Password in chat, screenshots, ZIP files or public repositories.
Restart npm start after editing .env. There is no need for each student/instructor to create an App Password.
Google may restrict App Passwords on managed school/work accounts or Advanced Protection accounts.
If unavailable, use an eligible Gmail sender account. Changing the sender's Google password revokes App Passwords.
Official help: https://support.google.com/accounts/answer/185833

TEST
1. Register an account using a real email address you can open. Example addresses used in earlier demonstrations cannot receive mail.
2. Sign out. Click Forgot password? below the login form.
3. Enter that account's registered email and click Send reset code.
4. Open its inbox/spam folder. Enter the newest 6-digit code in ExamPortal.
5. Enter and confirm a new password, then click Update password.
6. Sign in using the new password. The old password should fail.
Only the sender needs Gmail configuration; recipients use their ordinary inbox.

TROUBLESHOOTING
If Password reset email is not configured appears, check GMAIL_USER and GMAIL_APP_PASSWORD and restart the server.
If a code does not arrive, use node scripts/check-gmail.js, check inbox/spam, confirm the account email and observe resend limits.
The public response is deliberately the same for unknown emails, throttled requests and delivery failure.
Email delivery errors appear as a generic server message without passwords or reset codes.
Internet access and Google's mail service are required to send/receive email. Other application features remain usable offline.
If rate limits are hit, wait; five wrong guesses require a new code once resend limits permit it.
