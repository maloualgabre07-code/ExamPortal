ExamPortal — Final Balanced Dark Green Sidebar

This ZIP contains the complete existing project with the SIDEBAR fixed.

IMPORTANT: The page loads BOTH public/style.css and public/REFERENCE-MATCH.css, in that order. Previously, later rules in REFERENCE-MATCH.css overrode changes in style.css. This update consolidates the sidebar layout in the last-loaded file.

Desktop sidebar: logo and school name at top; Assessment Workspace label 34px below branding; Overview through Profile with consistent small gaps; Sign Out anchored above an 88px landscape footer. Short-screen layout adjusts automatically; page can scroll the sidebar when necessary.

How to run:
1. Extract ZIP into a fresh folder.
2. Copy the .env from your working project. Never share .env.
3. Open the extracted folder in VS Code.
4. Run npm install if dependencies are absent, then npm start.
5. Visit http://localhost:3000 and press Ctrl+Shift+R.

No DB migrations or examination logic were changed. The role-specific navigation is generated by public/app.js.
