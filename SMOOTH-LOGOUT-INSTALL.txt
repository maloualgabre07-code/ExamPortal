EXAMPORTAL SMOOTH LOGOUT UPDATE

Sign Out now opens a full-screen fade-in loading overlay with a rotating spinner and Signing you out… text.
It stays visible for at least 450 milliseconds while the server signs out. Repeated clicks are blocked.
Reduced-motion preferences are respected.
A successful logout clears the workspace and opens a clean login form with the email field focused.
No browser reload is needed. A fresh session token is obtained automatically on the next sign-in.
Active examination answers are saved before logout. The timer continues on the server.
If saving or signing out fails, the user stays signed in and sees a retry message.
Normal logout has no confirmation dialog; an active examination still asks before leaving.
