Fresh Orchard BCC ExamPortal theme

For an existing working ExamPortal installation:
1. Back up your current public/style.css.
2. Extract this ZIP.
3. Copy public/style.css from the ZIP to your working ExamPortal public folder.
4. Keep your existing school image file public/bcc-campus-background.jpg.
5. Refresh Chrome using Ctrl+F5.

The theme changes only CSS. Existing JavaScript, exams, SEB security, and PostgreSQL data are not changed.
